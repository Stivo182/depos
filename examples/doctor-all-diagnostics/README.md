# Все диагностики `doctor`

Пример содержит один `packagedef`, исходники с использованиями пакетов и управляемый
каталог `oscript_modules`.

Основной запуск из корня репозитория:

```powershell
oscript src/cmd/main.os doctor -m examples/doctor-all-diagnostics/packagedef -v
```

Он показывает все типы диагностик. Ошибки `diag-missing`, `diag-broken`, ветки
`diag-conflict-*` и корни `diag-transitive-*-root` намеренно делают отдельные ветки графа
неполными. В разделе транзитивных конфликтов воспроизводятся все причины: несовместимые
требования, неподходящая установленная версия, неустановленный и поврежденный пакет.
